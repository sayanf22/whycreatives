## Step-by-Step Migration Checklist

### 1. Create New Supabase Project
- Go to https://supabase.com/dashboard
- Create a new project (choose `ap-south-1` for India)
- Copy the new Project ID, URL, Anon Key, and Service Role Key

### 2. Run the Schema Migration
- Go to **SQL Editor** in the new Supabase dashboard
- Open and run `supabase/migrations/00001_full_schema.sql`
- This creates all tables, indexes, RLS policies, storage bucket, and admin user

### 3. Import Seed Data
```bash
set NEW_SUPABASE_URL=https://NEW_REF.supabase.co
set NEW_SUPABASE_SERVICE_KEY=your_service_role_key
node supabase/import_data.mjs
```

### 4. Re-upload Storage Files
- Download files from the old storage URLs listed above
- Upload them to the new project's `portfolio-images` bucket under `portfolio/` folder
- Update `portfolio_works.image_url` in the database with new URLs

### 5. Deploy Edge Functions
```bash
npx supabase functions deploy generate-daily-insight --project-ref NEW_REF
npx supabase functions deploy sitemap-blog --project-ref NEW_REF
```

### 6. Set Edge Function Secrets
- Go to new project → Settings → Edge Functions → Secrets
- Add `GROQ_API_KEY`

### 7. Enable Cron Job
- Uncomment and update the cron job SQL in `00001_full_schema.sql` section 7
- Replace `NEW_PROJECT_REF` with your new project ref
- Run in SQL Editor

### 8. Update Application Config
- Update `.env` with the new Supabase URL, Project ID, and Anon Key
- Update `supabase/config.toml` with the new project ID
- Update `src/integrations/supabase/client.ts` if it hardcodes URLs

### 9. Test
- Run `npm run dev` and verify all pages work
- Test admin login at `/admin-login`
- Test portfolio gallery, insights, and contact form

### 10. Deploy
- Push changes and deploy to Cloudflare Pages
- Verify the production site
